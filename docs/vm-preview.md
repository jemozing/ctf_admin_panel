# Просмотр панели и сервисов через SSH

Инструкция использует пример SSH-адреса `user@VM_HOST`. Подставьте своего пользователя и адрес VM; порт SSH зависит от настройки сервера или проброса VirtualBox. Панель и игровые сервисы должны быть уже запущены на VM. Учетные данные первого Admin задаются при [установке](container-deployment.md), а затем используются для входа через браузер.

Откройте туннель на своём компьютере и оставьте терминал работающим:

```bash
ssh -N -T -p 22 \
  -o ExitOnForwardFailure=yes \
  -o ServerAliveInterval=30 -o ServerAliveCountMax=3 \
  -L 127.0.0.1:18765:127.0.0.1:8765 \
  user@VM_HOST
```

После подключения откройте http://127.0.0.1:18765/. Здесь `18765` — свободный локальный порт, `8765` — пример loopback-порта dashboard на VM. При другом опубликованном порте измените правую часть `-L`. SSH использует настроенный ключ или интерактивный запрос пароля; пароль не требуется помещать в команду.

Для доступа к играм добавьте по одному перенаправлению на каждый нужный TCP-порт. Ниже приведён пример для подготовленных тестовых профилей SibirCTF; фактические порты сверяйте с Compose и подтверждённой конфигурацией сервисов:

```bash
ssh -N -T -p 22 \
  -o ExitOnForwardFailure=yes \
  -o ServerAliveInterval=30 -o ServerAliveCountMax=3 \
  -L 127.0.0.1:18765:127.0.0.1:8765 \
  -L 127.0.0.1:18011:127.0.0.1:18011 \
  -L 127.0.0.1:18012:127.0.0.1:18012 \
  -L 127.0.0.1:18013:127.0.0.1:18013 \
  -L 127.0.0.1:18014:127.0.0.1:18014 \
  -L 127.0.0.1:18015:127.0.0.1:18015 \
  user@VM_HOST
```

| Пример сервиса | Вход на компьютере с туннелем | Клиент |
|---|---|---|
| Dashboard | http://127.0.0.1:18765/ | Браузер |
| BioGuard | http://127.0.0.1:18011/ | HTTP / браузер |
| ncdex | http://127.0.0.1:18012/ | HTTP / браузер |
| CyberBank | http://127.0.0.1:18013/ | HTTP / браузер |
| neuroLinks | `127.0.0.1:18014` | Клиент текстового TCP-протокола |
| EyeSee | `127.0.0.1:18015` | gRPC-клиент |

SSH local forwarding передаёт TCP. Для UDP нужны отдельный подходящий туннель и явная настройка маршрутизации. Привязка локальных концов к `127.0.0.1` ограничивает доступ компьютером, где запущен SSH. Остановить туннель можно через Ctrl+C.

## Статус исторического VM-стенда

На стенде Linux/amd64 с 4 vCPU, 4 GiB RAM и диском 40 GiB в октябре 2026 года панель и пять сервисов были развёрнуты; короткие HTTP/TCP/gRPC-пробы прошли. Позднее повторились kernel stalls и потеря SSH. Четыре новых игровых цикла завершены, финальный итог EyeSee неизвестен. Последняя доступность не подтверждена, полная нагрузочная и аварийная приёмка отложена. Proxy/WAF и пакетный анализ после этих изменений на VM не принимались.

Подробности: [исторический запуск](../tests/integration/reports/README.md#report-native-five-sibir-review-ready-2026-10-29-json), [незавершённая серия](../tests/integration/reports/README.md#report-native-current-acceptance-2026-10-29-json), [матрица A01–A39](progress.md#матрица-a01a39). Инструкция выше описывает способ подключения и не подтверждает текущее состояние какого-либо хоста.
